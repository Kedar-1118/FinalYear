Core Contributions

Four Algorithmic Innovations

Building upon Tiwari et al. (NeurIPS 2022) with four formal theoretical and systems contributions.

1

Serfling Finite-Population Bounds

Replaces naive Hoeffding bounds with concentration inequalities that account for sampling without replacement. Uncertainty collapses to exactly zero when all samples are observed.

ε = √(2σ²·κ(n,N)·ln(3/δ)/n) + 3·ln(3/δ)·κ(n,N)/n
where κ(n,N) = max(0, 1 − (n−1)/N)
2

Adaptive Dynamic Minibatch (ADMA)

Dynamically scales batch size with the shrinking active arm set. When 80% of candidates are eliminated, batch size drops automatically — cutting sample evaluations by 20–30%.

M_t = max(M_min, ⌊M₀·(|Active_t|/K)^α⌋)
3

Hierarchical Coarse-to-Fine (H-MAB)

Two-stage tournament: coarse screening at 16 bins eliminates weak features, then survivors compete at full 256-bin resolution — with a formal Bonferroni δ-budget split.

δ = δ_coarse + δ_fine = δ/3 + 2δ/3
4

Depth-Adaptive Hybrid Solver

Near tree leaves (N < 500), MAB overhead exceeds brute-force cost. The HybridSolver switches to vectorized exact sorting for 70%+ of tree nodes, eliminating overhead at leaf levels.

Solver = { Exact Sort if N < 500 | MAB if N ≥ 500 }

Systems Engineering

Memory & Performance Optimizations

Great algorithms need great systems engineering to deliver real-world speed.

📦

uint8 Columnar Representation

Continuous features pre-binned into 256 discrete bins stored as uint8 (1 byte vs 8 bytes per float64), yielding an 8× memory reduction and enabling SIMD cache streaming.

🧊

Fortran-Order Memory Layout

Data stored column-by-column (order='F') ensures sequential memory access during per-feature histogram scans — maximizing L1/L2 cache hit rate.

♻️

Zero-Allocation Scratch Buffers

All histogram, Welford, and bounds buffers pre-allocated once before training. Zero GC pauses inside recursive tree building — 0% memory re-allocation.

🔥

Numba JIT + C++17 Dual Engine

Python kernels compiled to native machine code via Numba @njit. Standalone C++17 engine for maximum throughput — 3.12ms per node split.
